# Bytewarden Send

This folder contains 2 packages that can be used to create and modify Sends.

## semd-core

Package name: `@bytewarden/send-core`

Contains all types, models, and services for Bytewarden Send

Currently in use by the Bytewarden Web Vault, CLI, desktop app and browser extension

## send-ui

Package name: `@bytewarden/send-ui`

Contains all UI components used for Bytewarden Send
